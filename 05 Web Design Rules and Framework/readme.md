## Website Personality &mdash;

1. Serious/Elegant: luxury and elegance, based on thin self typefaces, golden or pastel colors, and big high-quality images

2. Minimalist/Simple: Focusses on the essential text content, using small or medium-sized sans-serif black text, lines, and few images and icons

3. Plain/Neutral: Design that gets out of the way by using neutral and small typefaces, and a very structured layout. Common in big corporations

4. Bold/Confident: Makes an impact, by featuring big and bold typography, paired with confident use of big and bright colored blocks

5. Claim/Peaceful: For products and services that card, transmitted by calming pastel colors, soft serif headings, and matching images/illustrations

6. Startup/Upbeat: Widely used in startups, featuring medium-sized sans-serif typefaces, light-grey text and backgrounds, and rounded elements

7. Playful/Fun: Color and round designs, fueled by creative elements like hand-drawn icons or illustrations and fun language

### Typography &mdash;

Typography ဆိုတာ Text ကို လှပပြီးဖတ်ရလွယ်ကူအောင် ပြုလုပ်ခြင်း ဖြစ်ပါတယ်။

Serif and San-Serif

#### Serif

- Creates a traditional/Classic look and feel
- Conveys trust worthiness
- Good for long text (eg. Article or Online Magazine)

#### Sans-Serif

- Modern look and feel
- Clean and simple
- Easier to choose for beginner designer!

### Use GOOD TYPEFACES &mdash;

1. အသုံးများတဲ့ Typefaces တွေကိုသာ အသုံးပြုပါ (ကြည့်ရဆိုးတဲ့ typeface တွေကို မရွေးချယ်ဖို့ လို)

2. Sans-Serif Typefaces
   1. Inter (Google Font, Font Squirrel)
   2. Open Sans
   3. Roboto
   4. Montserrat
   5. Work Sans
   6. Lato

3. Serif Typeface
   1. Merriweather
   2. Aleo
   3. playFair Display
   4. Cormorant
   5. Cardo
   6. Lora

   တို့ဟာ အသုံးများတဲ့ typeface ဖြစ်ပီး အန္တာရယ်ကင်းကင်းအသုံးပြုနိုင်ပါတယ်။

4. page တစ်ခုမှာ typeface တစ်ခုသာသုံးသင့်ပါတယ်။ အကယ်၍ ပိုသုံးချင်ရင် အများဆုံး 2 မျိုးသာ သုံးသင့်ပါတယ်။

5. မှန်ကန်တဲ့ typefaces ဖိမို့ website personality ပေါ်မူတည်ပီး ဆုံးဖြတ်ရမယ်။

6. Font Size and Weight
   1. project အတွက် font size ကို type scale tool သို့မဟုတ် ကြိုတင်စီစဉ်ထားသင့်တယ်။
   2. Normal text အတွက်ဆိုရင် 16px ကနေ 32px အထိ သုံးသင့်(ဥပမာ - Nav(16px), Testimonial(18px))
   3. Long text(like a blog post) အတွက်ဆိုရင်တော့ 20px သို့မဟုတ် 20px ထက်ကြီးတာ သုံးသင့်
   4. Headlines အတွက်ဆိုရင် personality ပေါ်မူတည်ပီး 50px+ and bold(600+) သုံးသင့်
7. ဘယ် text ကိုမှ `font-weight` 400 အောက် မသုံးသင့် (စာဖတ်ရခက်နိုင်)
8. စာကြောင်းတစ်ကြောင်းမှာ character 75 လုံးအောက်ပဲ အသုံးပြုသင့်(များရင် မျက်လုံးညောင်းပီး စာဖတ်ရတာ အဆင်မပြေ)
9. Normal Text အတွက် `ling-height` ကို 1.5 ကနေ 2 အထိသုံးသင့်ပီး Big text အတွက်ဆိုရင် 1.5 အောက်ပဲ(1.1, 1.2)သုံးသင့်(text က ပို small ဖိလေလေ ၊ ပိုရှည်လေလေ ဆို line-height ပိုလို)
10. Headline က unnatural ဖိနေတယ် ထင်ရင် `leter-spacing` ကို လျော့ချကျိပါ။
11. text ကို all-caps နဲ့ short title ပြုလုပ်မယ်ဆိုရင် သေးပီးတော့ bold ဖြစ်အောင်လုပ်ပီး `letter-spacing` ကို တိုးပေးပါ
12. Don't Justify text.
13. Don't center long text block

### Colors &mdash;

1. color ဟာလည်း web presonality ပေါ်မူတည်ပီး အဓိပ္ပါယ်ရှိသော အရောင်တွေကို ရွေးသင့်တယ်။
   1. Red : a lot of attention, symbolizes power, passion and excitment
   2. Orange : aggressive, convey happiness, cheerful and creativity
   3. Yellow : Joy, Happiness and intellenge
   4. Green : Harmony, Nature, Growth and Health
   5. Blue : Peace, Trustworthiness and professionlism
   6. Purple : wealth, wisdom and magic
   7. Pink : Romance, care and affection
   8. Brown : Nature, durability(ကြံခိုင်မှု) and comfort
   9. black : alittle lik red, power, elegance minimalism, otherhand grief(ဆုံးရှူံးမှု)၊ sorrow(ဝမ်းနည်းမှု)
2. Choose Good Color tone. Don't choose random tone or css name colors.
3. Don't use complete color, use tint and shape color
4. choose `primary-color `by website personailty and `grey color`(grey color can be other dark color)
5. And You can use one more color(`accent color`) by using `color palette`(don't use random color)
6. `primary color` use emphasize button and element
7. `accent color` should use component, section stand out.
   1. coolors
   2. Tailwind CSS
   3. Open color
   4. Flat UI Colors 2
   5. Palleton.com
   6. tint & shade Generator

### Shadow &mdash;

1. website personality က လှနေပီဆိုရင် shadow သုံးမို့မလိုတော့ဘူး
   1. less shadow (serious/elegant design)
   2. more shadow (Fun/playful)
2. shadow ကို အနည်းငယ်ပဲ သုံးပါ။ el တိုင်းကို shadow မထည့်ပါနဲ့
3. Shadow ကို အရမ်းမှောင်မှောင်ကြီး မသုံးပါနဲ့ အရောင်ဖျော့ဖျော့သုံးပေးပါ
4. attention ရမို့အတွက် small el တွေကို small shadow သုံးသင့်ပါတယ်
5. larger area တွေကိုတော့ medium sized shadow တွေသုံးခြင်းအားဖြင့် attention ရစေပါတယ်။
6. model box, Navigation and pop up box တွေကိုတော့ large shadow တွေ အသုံးပြုကြပါတယ်။
7. mouse interaction တွေမှာလည်း shadow အသုံးပြုပါတယ်။ (click, hover)
8. Experiment with glows. colored shadows

### Border-radius &mdash;

1. border-radius increase playfulness/fun decrease serious/elegant
2. Typeface have a certain roundness: make sure that border-radius matches that roundness!
3. Use in button,image, around icons, standout sections and other elements

### Whitespace &mdash;

1. မှန်ကန်တဲ့ whitespace ဟာ design ကို clean, modern and polished ဖိစေတယ်။

2. Whitespace က အခြားသော အစိတ်အပိုင်းတွေကို ချိတ်ဆက်ပေးတယ်။

3. Section တွေကြားမှာ whitespace ကို အများကြီးသုံးသင့်တယ်။

4. Use a lot of whitespace between group of elements

5. use whitespace between elements

6. inside groups of el, try to use whitespace instead of lines

7. The more some el (or groups of el) belong together, the closer they should be!

8. whitespace အများကြီးနဲ့ စပီး တဖြည်းဖြည်းလျော့ ကြည့်ကောင်းတဲ့အနေထားထိရအောင်
